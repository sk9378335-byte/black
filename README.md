# BLACK DRAGON — Vercel + GitHub Website

Static, responsive website for the Black Dragon incense-stick brand.

## Files
- `index.html` — Home
- `about.html` — About
- `products.html` — Products
- `contact.html` — Contact
- `style.css` — Website styling
- `main.js` — Contact form behavior
- `images/` — Product photos
- `vercel.json` — Vercel static-site configuration

## GitHub
Upload the **contents of this folder** to the root of your GitHub repository.

## Vercel
1. Push this folder to GitHub.
2. Open Vercel and import the GitHub repository.
3. Framework Preset: **Other** (or leave detected/default).
4. Build Command: **leave empty**.
5. Output Directory: **leave empty**.
6. Deploy.

No Node.js server is required.

## Contact form
This version is static/Vercel-safe. The contact form opens the visitor's email app and prepares an enquiry email to:
`hello@blackdragon.in`

Change that email in `main.js` if needed.

## Important
The website uses the supplied Black Dragon product images. Replace the placeholder phone number/email in `contact.html` with the actual business details before publishing.
